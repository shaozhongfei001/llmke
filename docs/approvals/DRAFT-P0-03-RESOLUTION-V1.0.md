## 1. 为什么它是阻断（一句话）

旧实现的图检索入参不携带文件范围，且邻近块 / 图片回查 / 多版本扩召回会**二次取数**——
授权只在"最终引用列表"上兜底，而 LLMKE 的合同要求**进入 LLM 的上下文**逐路受控。

## 2. 四项裁决（请在「选择」列打勾；不改建议值就在「采纳建议」打勾）

### D-03-1 授权粒度

| 选项 | 含义 | 选择 |
|---|---|---|
| **A（建议）** | 叶子权限落**文件**；目录/KB 作为聚合快捷方式 | **☑ 采纳建议** |
| B | 只做 KB 级（全有或全无） | ☐ 选 B |
| C | 目录级（同目录不同密级无法区分） | ☐ 选 C |

**不采纳 A 的后果**：无法满足"派生资产按完整叶子授权复核"，同 KB 内敏感文件只能整块开放或整块拒绝。
**改法**：若选 B/C，请在签署页写「替代方案：<内容>」。

### D-03-2 多来源合并与拒绝优先级

| 选项 | 含义 | 选择 |
|---|---|---|
| **A（建议）** | `deny 优先`（任一来源 deny 即拒）+ 授权版本号 + 撤权即时失效（缓存带版本） | **☑ 采纳建议** |
| B | 多来源取并集（任一宽松来源即可放行） | ☐ 选 B |
| C | 由网关统一裁决，内部服务不校验 | ☐ 选 C |

**不采纳 A 的后果**：B 会让最宽松的授权源放大权限；C 会让"绕过网关直调"成为后门（对应 §3 的 E7）。

### D-03-3 FAQ 是否继承来源约束

| 选项 | 含义 | 选择 |
|---|---|---|
| **A（建议）** | **继承**：FAQ 命中后按其来源文档复核权限 | **☑ 采纳建议** |
| B | 不继承（沿用旧方案"FAQ 召回不受数据授权影响"） | ☐ 选 B |

**不采纳 A 的后果**：未授权文件派生的问题可被召回，等于授权留后门（对应 E3）。

### D-03-4 图路在无法文件级隔离时的处置

| 选项 | 含义 | 选择 |
|---|---|---|
| **A（建议）** | 仅当请求方对**整 KB** 已授权时开放图路；否则图路不参与并在结果中标 `degraded` + 覆盖度 | **☑ 采纳建议** |
| B | 图路一律关闭（`graph disabled`，不阻断非图平台） | ☐ 选 B |
| C | 图路照常参与，靠事后过滤 | ☐ 选 C |

**不采纳 A/B 的后果**：C 会在图回填阶段引入越权内容（对应 E5）。
