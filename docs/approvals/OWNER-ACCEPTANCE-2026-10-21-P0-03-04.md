## 2. 由此确定的口径（可直接据此写实现与验收用例）

### P0-03（授权）

| 决策 | 确定值 |
|---|---|
| 授权粒度 | 叶子权限落**文件**；目录/KB 为聚合快捷方式 |
| 合并与优先级 | **deny 优先**（任一来源 deny 即拒）+ 授权版本号 + 撤权即时失效（缓存带版本） |
| FAQ 继承 | **继承**：FAQ 命中后按来源文档复核权限（推翻旧方案"FAQ 不受数据授权影响"） |
| 图路 | 仅当请求方对**整 KB** 已授权时开放；否则不参与并标 `degraded` + 覆盖度 |

### P0-04（代次）

| 决策 | 确定值 |
|---|---|
| generation manifest | **不可变**；修正只能新开 `generation_id` |
| 激活指针 | 每 KB **单原子指针**；切换不逐后端 |
| 任务与状态 | 算法侧**不写业务状态**；任务入持久表 + `fencing_token`；业务变更走 outbox + 补偿 |
| 写入约束 | 必须带 `(kb_id, generation_id, fencing_token)`；非当前代写入**返回明确错误** |
