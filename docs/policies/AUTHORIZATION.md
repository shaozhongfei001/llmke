# 授权边界与信息泄漏控制

外部身份先认证；业务侧根据用户/部门/机构组及拒绝优先级裁决，再签发AuthContext。算法侧校验JWS、issuer、audience、request_id、KB/文件范围、auth_version、resource_version和有效期；不是相信请求里的subjects。签名key按kid受控轮换，禁止none/未批准算法。目标文件/目录/KB粒度及FAQ权威来源需以P0-03真实批准关闭。

文件模式deny优先；空allowlist拒绝；同请求固定授权和激活快照。索引召回、邻近块、图片、图回填、缓存、历史引用解析与上下文取数每次继承范围/重新校验。文件登记缺权限policy拒绝；物理空间由授权KB和generation映射，不接受用户空间名。

社区检测/摘要/节点统计/图排序特征必须只由该授权可见集计算。不能用组织名冒充一致授权域；重叠授权集并不天然等价。域缓存键至少含规范化可见来源集指纹、授权版本、KB和generation。撤权后旧域产物立即不可查询，异步清理不延迟围栏。

范围无法证明时禁用该图路，记录permission_scope_unsupported并走已授权的其他通路；不接受全局建图后过滤、部分来源可见就展示完整摘要、只过滤最终引用。派生资产使用完整叶子集合，而非显示的少数引用。

非干扰验收：固定查询与已授权数据，只变更未授权数据，授权上下文内容、可见计数、通路状态/缓存可见信号不得随之变化。需检查进入LLM的上下文；最终引用合规不能证明前文无泄漏。此保证针对受控知识加工/检索，不能冒称证明了基础模型训练数据隐私。时延/容量侧信道另按真实威胁模型测量，不宣称文字合同已在信息论上证明安全。
