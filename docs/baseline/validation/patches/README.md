# patches/ 目录约定

本目录位于 `docs/baseline/validation/`，是**冻结排除前缀**（不参与 `control_digest` /
`doc_digest`）。这意味着放在这里的文件**不会被任何摘要覆盖**——因此必须限制其用途。

## 规则

1. **只放结论，不放可执行补丁。**
   本目录允许放：验证报告、复核记录、被采纳补丁的**说明**。
   不允许放：可直接 `git apply` 的 `.diff`、脚本、可执行二进制。

2. **补丁一律放仓外或被否决目录。**

   | 位置 | 用途 |
   |---|---|
   | `~/data/dev/coordination/patches/` | 待应用的补丁（仓外，不随仓库分发） |
   | `~/data/dev/coordination/rejected/` | 被否决的补丁（保留证据，禁止应用） |

3. **原因**：`docs/baseline/validation/` 不被任何摘要覆盖，若允许放可执行补丁，
   就等于"可以被无痕塞入可执行内容而不改变任何摘要"。这是本项目已实际利用过的通道
   （W-01 / W-05 / W-07 的补丁都曾放在这里），独立 QA 在 2026-10-22 明确指出该风险。

4. **例外需登记**：确需在本目录放补丁时，必须在 `docs/policies/CHANGE-REQUESTS.yaml`
   登记，并说明为何不能放仓外。未登记的补丁文件视为违规。

## 现状

  按规则 1 它不应再留在此处；因已应用且不可再改变任何结论，暂留并在下一窗口迁出仓外。
