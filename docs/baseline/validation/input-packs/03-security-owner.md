| # | 材料 | 格式 |
|---|---|---|
| 1 | E1 授权上下文规范（`AuthContext` 字段、签名、失效语义） | 文档，含字段表 |

## 需要你明确裁决的三点

1. 草案中的「deny 优先 / 撤权即时 / FAQ 按来源复核 / 图路仅整 KB 开放」是否**正式采纳**？
2. 侧信道（社区数量/成员/分数）与错误元数据是否**纳入** E2–E7，还是另立？
3. 缓存隔离的判据是「版本号变化即失效」还是「TTL 内允许陈旧」？

## 验收规则

1. 每条负例给出 `DENY` 或 `degraded` 的**响应样例**，且响应不含内容片段；
2. 拒绝与不存在必须**不可区分**；
3. 日志含环境标识；模拟/夹具结果**不得**充当实测。

## 常见拒收

用测试夹具当生产证据；只给「已修复」结论无日志；策略口头确认无书面记录。
