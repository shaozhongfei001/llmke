# 10 前端交互设计

> 状态：**设计草案**。当前前端沿用 R12 页面，本文件定义 V2 接口所需的交互与状态。
> V2 的后端返回已含 `route`、`citations`、`version_filter.stats`、`BACKPRESSURE` 等字段，前端必须能表达。

## 1. 问答页状态机

| 状态 | 触发 | 界面 |
|---|---|---|
| idle | 初始 | 输入框 + 示例问题 |
| loading | 已提交，未出首字 | 骨架屏，可取消 |
| streaming | 正在出字 | 逐字显示，引用角标后置补齐 |
| done | 回答完成 | 引用可点，显示来源文件与页码 |
| empty | 无命中（`READY_EMPTY`） | "未找到依据"，给改写建议；**不编答案** |
| partial | 有答案但引用校验未过 | 答案标"未通过引用校验"，默认折叠 |
| denied | 无权限 | 统一话术，不透露资源是否存在 |
| error | 失败 | 区分可重试/不可重试，给 trace_id |

## 2. 引用展示

- 正文用角标 `[1][2]`，点击打开右侧原文并高亮命中片段。
- 引用必须显示：文件名、页码/区间、快照版本。
- **无引用的断言不能出现在答案里**；若模型给出无引用内容，前端标为"未标注来源"。

## 3. 失败与积压

- `BACKPRESSURE`：显示"已收到，当前排队已满，约 N 秒后可重试"，给倒计时与重试按钮；不承诺完成时间。
- 超时：保留已输出内容，提示"回答未完成"，可重试。
- 服务降级（DENSE_FALLBACK）：答案区标注"图检索不可用，当前为向量检索结果"。

## 4. 文档与重建

- 上传后显示阶段：解析 → 校验 → 构建 → 发布，**阶段独立**，不能用一个"处理中"糊过去。
- `PARTIAL`/`EMPTY` 产物必须显式提示缺什么能力。
- 重建中：旧版本仍可查，标注"新版本构建中"。

## 5. 可访问性与国际化

- 键盘可达；引用侧栏可 Esc 关闭。
- 文案不写死中文，预留资源键。
- 颜色不作为唯一状态标识（失败/降级同时用图标与文字）。
