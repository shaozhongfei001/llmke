# 演示用图谱库选择与测试用例（kb_9，2026-11-02）

## 一、为什么选 kb_9

同一套栈里四个库有图数据（Milvus `graph_base`）：

| 库 | 实体 | 三元组 | 社区摘要 | 说明 |
|---|---|---|---|---|
| **kb_9** | **156** | **269** | **10** | 唯一同时具备"多版本 + 表格 + FAQ + 社区"的库 |
| kb_22 | 37 | 29 | 4 | 社区有，但文档少 |
| kb_26 | 30 | 13 | 0 | 只有实体/三元组 |
| kb_1000 | 8 | 14 | 0 | 近乎空库 |

kb_9 的构成（ES 270 块 / 12 个文件）：

- 业务夹具 8 份：`R12FIX-product-loan.docx`（V0/V1 两版）、`R12FIX-product-intro.pptx`（V0/V1）、
  `docx-plain.docx`、`docx-table.docx`、`pdf-digital.pdf`、`pdf-scanned.pdf`；
- 英文噪声 1 份：`Allotmentmonthbymonth-DK...pdf` 占 **258/270** 块；
- 表格块 2 条、FAQ 20 条、社区摘要 10 条。

> 注意：噪声文件占比极高，**top_k 小于 10 时容易只召回英文书**。演示时建议 `top_k>=10`，
> 或问题里带上业务实体名（实测带实体名时业务块稳定进 top-2）。

## 三、怎么跑

```bash
# 1) 向量+图检索（本地，无鉴权，最强单条验收入口）
curl -s -X POST http://127.0.0.1:19995/retrieval_documents \
  -H 'Content-Type: application/json' \
  -d '{"query":"智造贷单户最高授信额度是多少","knowledge_base_name":["kb_9"],
       "enabled_graph":true,"top_k":10}' | jq '.data.documents_list[0:2]'

# 2) GraphRAG global
curl -s -X POST http://127.0.0.1:19995/retrieval_documents_global \
  -H 'Content-Type: application/json' \
  -d '{"query":"这个库主要讲了哪些主题","knowledge_base_name":["kb_9"],"top_k":5}'

# 3) 端到端问答（需登录拿 token，经网关）
#    POST http://127.0.0.1:8088/auth/login  {"username":"admin","password":"..."}
#    POST http://127.0.0.1:8088/qa          {"question":"...","kb":"kb_9"}
```

实测延迟（`enabled_graph=true`，本机）：单条检索 **5–10 秒**；冷启动首次约 30 秒。

## 四、判据建议（别只看"有没有返回"）

1. **答案数字必须是原文子串**：`8000万元`、`3000万元` 这些字符串要能在命中块里找到，
   否则模型在编；
2. **引用可回溯**：每条引用要能解析出 `.../kb_9/<文件名>/<版本>/...`；
3. **版本正确**：B1 的引用路径必须是 `V1`；
4. **枚举完整**：A4（三个档位）、A6（三条产业链）、C4（两家 AA）缺一即错；
5. **负例不编**：G1/G2 必须说"未提及"，答出具体数字即失败。

## 五、已知问题（演示时会碰到）

- `GET /index/kbFile/multiVersion` 404：版本列表接口未就绪，检索侧已优雅降级（日志有告警，不影响答案）；
- 英文噪声占 258/270 块：`top_k` 太小会召回 DK 园艺书，与业务无关；
- `R12FIX-*` 文件里明写"验收测试夹具，非真实业务文件"，对外演示时注意口径。
