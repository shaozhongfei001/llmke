## 一句话结论（供评审先读）

当前「上传 → 12340 解析 → 双写 ES/Milvus → 19531 从 ES 全库取块 → 18094 全量 rebuild」的链路里，doc2md 不在主链、搜索与图谱不同源、且没有任何「发现更新」的 diff；本方案把唯一解析者切到 doc2md，用一次 `store.commit` 的不可变快照同时派生搜索载荷与 BuildDoc，并把「按库 diff（平台侧）→ 全库 wanted texts（传给引擎）→ HippoRAG `apply_delta` 按文本差集增量抽取 → 重算 sources/community → `check_freshness` 短路无变化回调」接成一条闭环。

**关键诚实边界**：HippoRAG 2.0.0a4 的增量是「增量抽取 + 全量重建图」，不是增量图更新；本方案不宣称后者。

**评审结论**：本包已由独立评审智能体完成证据级复核，结论为「有条件通过」，进 P1 前需闭环 `07-REVIEW-OUTCOME.md` §九 的 5 项待办（含 C12 / C9 / C10 等 Owner / 业务方裁定）。
