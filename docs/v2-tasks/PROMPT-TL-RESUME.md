# LLMKE HippoRAG-only 长程任务接续指令（RESUME｜中断后继续）

用于会话/进程中断后的恢复，不是新的开工提示词。开工读 START，中断读本文件。

## 接续步骤

1. 读 `docs/v2-tasks/TASKBOOK.md`、`TASKS.yaml`、`CHECKPOINT.md`（若存在），并 `git -C ~/data/dev/llmke-v2 status`（另核对 `~/data/dev/llmke`、`~/data/dev/llmke-r12`）。
2. 核对 `TASKS.yaml` 的 `meta.base_commit` 与当前 HEAD；不一致先修正事实与依赖，不盲目继续。
3. 从 `CHECKPOINT.md` 的“下一精确动作”继续；无检查点时，从 `TASKS.yaml` 中 `state: TODO` 且 `depends_on` 已满足的第一项开始。
4. 继续执行 START 任务书的全部 D0–D10；不从头规划，不重做已生效的迁移、上传、发布、合并等有副作用操作。
5. 阶段汇报后继续，不询问是否继续；只有全部真实验收满足才成功收尾。
6. 停止仅限：用户明确暂停、执行器/认证/预算真实限制、全部剩余工作确需无法自主获得的外部输入；此时保存检查点并标为未完成，写清恢复条件。

## 检查点模板（写入 `docs/v2-tasks/CHECKPOINT.md`）

```markdown
# 执行检查点
更新时间：
任务书：docs/v2-tasks/PROMPT-TL-START.md（base_commit bb32876）
当前工作树/分支/HEAD：
当前阶段（VL0–VL7）：
成果位置与当前版本：

## 已完成且验证
- 任务：实际结果：验收材料：

## 正在执行
- 任务/负责人：进程或作业标识：进展与结束判断：

## 未完成/失败
- 具体事项：已验证根因或假设：已尝试且无效的方法：只影响哪些依赖：

## 下一精确动作
1. 执行：2. 检查：3. 成功后：4. 失败后：

## 不得重复或擅自执行
- 已完成的有副作用操作：用户暂停/待授权事项：
```

恢复后先核对实际产物与仍在运行的任务，再从未完成项接续；不重复启动、不重做副作用。
