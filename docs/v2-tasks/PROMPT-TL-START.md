# LLMKE HippoRAG-only 长程任务书（START｜新会话开工）

你是本任务的执行负责人（TL），负责实际执行、必要分工、集成、验证和交付。

**不能以计划、盘点、建议或局部演示结束；阶段汇报后继续执行，不询问“是否继续”。**

## 1. 最终目标

为【用户】交付一套**只使用 HippoRAG 的知识库图引擎**，使其能通过【生产页面】完成：上传文档 → 自动解析 → 构建统一图 → 查看图谱 → 普通问答/全局问答 → 点开原文。

- 页面上的图谱、全局问答都必须来自 HippoRAG；旧自研图引擎退役。
- 全局/总结问答与图同源（社区建立在 HippoRAG 抽取事实之上，不用 HippoRAG 内部相似图，不用 legacy 抽取）。
- 中文默认可用（补丁默认安装，升级 HippoRAG 后重验）。
- 结论可定位到段落/表格单元格/图片；权限、更新、删除、撤权全程生效。
- 可离线部署，无云端暗依赖。
