# A02 同端点多谓词共存（组件级，COMPONENT）

- 时间：2026-10-29 20:1x
- 环境：真实 Nebula 3.8（127.0.0.1:19669），临时空间，测完即删
- 对照：同一对端点写两个不同谓词

## 实测

```
旧行为（不写 rank） A1->B1 : 1 条 ['担保方']      ← 后写覆盖先写
新行为（断言 rank） A2->B2 : 2 条 ['客户','担保方'] ← 两条共存
判定 PASS
```

## 结论

- 缺陷属实：Nebula 边唯一键 (src,dst,rank,type)，原实现 rank 恒 0 且谓词只作属性
- 修法有效：rank 由 (src,谓词,dst) 的 SHA1 前 60 位派生，不同谓词不同 rank
- 同时删除写边处的伪反向边（原 "B"->"A" show_flag=0），方向语义恢复；
  反向可达由查询侧无向 MATCH 承担
